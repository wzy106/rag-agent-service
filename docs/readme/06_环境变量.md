# 环境变量

复制 `.env.example` 为 `.env`，填写：

```env
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
MYSQL_PASSWORD=your_mysql_password
API_KEY=your-secret-key-here
# 多租户（可选，逗号分隔，每个 key 一个独立租户）
# API_KEYS=key_alice,key_bob
# RATE_LIMIT_PER_MINUTE=20
```

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | — | DeepSeek API 密钥 |
| `DEEPSEEK_BASE_URL` | — | DeepSeek API 地址 |
| `MYSQL_PASSWORD` | `root123` | MySQL 密码 |
| `API_KEY` | `dev-key-change-me` | 单租户 Bearer token |
| `API_KEYS` | — | 多租户 key 列表，设置后优先于 `API_KEY` |
| `RATE_LIMIT_PER_MINUTE` | `20` | 每分钟限流配额（按租户计） |
| `RAG_RECALL_K` | `20` | 混合检索粗排候选数 |
| `RAG_RERANK_MAX_LENGTH` | `512` | Reranker 输入截断长度 |
| `RAG_ENABLE_RERANK` | `1` | 置 `0` 关闭精排 |

**Docker 容器额外环境变量**（由 docker-compose.yml 注入）：

| 变量 | 值 | 说明 |
|---|---|---|
| `MYSQL_HOST` | `mysql` | 容器内用服务名，不用 localhost |
| `HF_HOME` | `/root/.cache/huggingface` | 模型缓存目录 |
| `HF_ENDPOINT` | `https://hf-mirror.com` | 国内镜像 |
| `HF_HUB_OFFLINE` | `1` | 离线模式 |
| `TRANSFORMERS_OFFLINE` | `1` | 离线模式 |
| `DATA_DIR` | `/app/rag_api/data` | checkpoints 持久化目录 |
