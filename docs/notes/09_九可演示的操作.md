# 九、可演示的操作

1. 打开 Swagger UI：http://127.0.0.1:8000/docs
2. 测普通对话：POST /chat
3. 测流式对话：POST /chat/stream
4. 查看对话历史：GET /history?thread_id=user_001（需带 `Authorization: Bearer <API_KEY>`，只返回自己租户的）
5. **演示持久化记忆**：问“MMR 是什么” → **`docker compose down` 完全销毁容器** → `up -d` → 问“它和普通相似度有什么区别” → 仍能理解
6. 演示会话隔离：换 thread_id 问“它是什么”
7. 演示降级策略：问“今天天气怎么样？” → 返回“知识库中没有找到相关信息”
8. 用浏览器打开 client.html，看打字机效果
9. 展示 Docker 一键启动：`docker compose up -d`
10. **展示评估可复现**：`python eval/eval_retrieval.py --test-set eval/test_set_v3_gold.json` → 输出 5 种策略 + source/chunk 双粒度 + 随机基线
11. **展示阈值标定**：`python eval/calibrate_distance.py` → 输出 easy/hard 负样本距离分布 + FPR/FDR
12. **展示测试集自动生成**：`python scripts/generate_testset.py` → 从 98 篇文档生成 v3 测试项（带 evidence chunk）
13. **展示两阶段检索日志**：`docker logs agent-api` → 看到 `[Rerank] 候选 20 条 → Top-3`
14. **展示鉴权与租户隔离**：配 `API_KEYS=key_a,key_b` → 两个 key 各建同名 `thread_id` 的会话，`/history` 互相查不到；不带 token 访问 → 401
15. 展示 GitHub 仓库：https://github.com/wzy106/rag-agent-service
