# 十六、项目数据汇总（最新）

- MySQL 表名：`conversations`（展示层）
- 新增接口：`GET /history?thread_id=user_001&limit=20`
- **知识库：98 篇文档 / 约 600 chunk（精确值以当前 `faiss_index` 和 `scripts/build_index.py` 输出为准）**
- 子目录文件数：notes 16、readme 13、stories 33、notes_interview 25
- **评估集：v3 测试项带 evidence chunk id；具体数量以 `eval/test_set_v3_gold.json` 为准**
- **检索指标：source strict/relaxed、chunk any/all、candidate recall@20、final recall@3 + Wilson/bootstrap CI；具体数字见根目录 README**
- **随机基线：source 级和 chunk 级两套，见 README**
- 混合检索参数：rrf_k=60, vector_weight=0.7, bm25_weight=0.3
- Rerank 参数：recall_k=20, final_k=3, RERANKER_MODEL="BAAI/bge-reranker-base"
- 降级阈值：MAX_DISTANCE=0.96（标定方法见 `docs/readme/09_阈值标定.md`）
- 阈值标定：正样本从测试集抽样，负样本分 easy（`negatives.json`）和 hard（`negatives_hard.json`）
- 阈值口径：`FPR = FP/(FP+TN)`、`FDR = FP/(TP+FP)`；**不是端到端幻觉率**
- Rerank 增益、混合检索 vs 相似度：见根目录 README 的当前评估表
- 端到端：`eval/eval_e2e.py`，输出 faithfulness/relevance/refusal + 2×2 交叉表
- 护栏参数：recursion_limit=10, max_tokens=2000
- 记忆：LangGraph checkpointer + AsyncSqliteSaver（容器重建不丢）
- 公共模块：`rag_core/search.py`
- 评估可复现：`python eval/eval_retrieval.py --test-set eval/test_set_v3_gold.json`
- 测试集生成：`python scripts/generate_testset.py`（成本约 ¥0.2–0.5）
- 多金标：`python scripts/label_gold.py --test-set eval/test_set_v3.json`
- 阈值标定：`python eval/calibrate_distance.py --positives eval/test_set_v3_gold.json --negatives eval/negatives.json eval/negatives_hard.json`
- GitHub 仓库：https://github.com/wzy106/rag-agent-service
