# 14. RAG 评估用什么指标？

**四个指标 + 随机基线**：

| 指标 | 公式 | 含义 |
|---|---|---|
| 召回率 | 命中数 / 总数 | 该找的有没有找到 |
| 精确率 | 平均（相关结果数 / Top-K 总数） | 找到的有多少是对的 |
| MRR | 平均（1 / 第一个正确结果的排名） | 第一个正确结果排多前 |
| 多样性 | 平均（Top-K 里不同文档数） | 结果覆盖多少不同来源 |
| 随机基线 | 1 - C(N-n,k)/C(N,k) | 从 N 个 chunk 里随机抽 k 个，命中期望 source 的概率 |

**实测数据**（249 个测试项，覆盖 83 篇文档）：

| 策略 | 召回率 | 精确率 | MRR | 多样性 |
|---|---|---|---|---|
| 普通相似度 | 52.2% | 0.24 | 0.40 | 2.63 |
| MMR | 41.0% | 0.16 | 0.35 | 2.79 |
| MMR + 去重 | 44.2% | 0.15 | 0.36 | **3.00** |
| 混合检索 | 54.6% | 0.24 | 0.45 | 2.60 |
| **混合检索 + Rerank** | **60.6%** | **0.27** | **0.49** | 2.60 |
| **随机基线** | **3.1%** | — | — | — |

**面试话术**：
> “我评估 RAG 用了四个指标 + 随机基线。随机基线用组合公式精确计算——从 583 个 chunk 里随机抽 3 个，命中期望 source 的概率是 3.1%。这里有个关键：**早期版本语料只有 2 篇文档、测试集只有 30 条，随机基线高达 84.1%，判别空间只有 15.9 个点**——Rerank 的提升被天花板效应压制，只有 +0.04 精确率。**扩语料到 98 篇、测试集到 249 条后**，随机基线降到 3.1%，判别空间 57.5 个点，**Rerank 的增益变成召回率 +6.0%、MRR +0.04**——这才是真实的增益。”
