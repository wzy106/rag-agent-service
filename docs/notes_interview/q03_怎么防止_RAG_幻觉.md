# 3. 怎么防止 RAG 幻觉？

**三层，但每一层都有边界：**

**第一层（Prompt 软约束）**
- 只使用资料中的信息，不要编造
- 资料不足时明确说“不知道”

**第二层（检索层降级）**
- 用向量距离阈值（`MAX_DISTANCE=0.96`）判断 query 是否离题
- 超过阈值时，检索工具返回“知识库中没有找到相关信息”

**第三层（生成层拒答）**
- 检索为空时，生成层应该直接拒答，而不是继续自由发挥
- 当前 Agent 实现里，工具只是返回一句自然语言，模型仍可能继续生成——这是已知限制
- 更可靠的做法是在 graph 层做分支，或用 LLM/reranker 做“资料是否充分”的判断

**加分项（精排）**
- 混合检索 Top-20 用 Reranker 精排 Top-3
- 减少不相关 chunk 进入上下文

**诚实的口径**
- 0.96 阈值衡量的是“检索层是否接受 query”，不是端到端幻觉率
- 负样本要分 easy（天气/菜谱）和 hard（近域但库内没有），否则会高估阈值效果
- 真正的幻觉率要用端到端 LLM-as-judge 的 faithfulness 指标测
