# 13. 检索不到内容怎么处理？

**当前实现（三层，但每层都有边界）**：

1. **检索层**：用向量距离做阈值（`MAX_DISTANCE = 0.96`），超过就返回空
2. **工具层**：收到空结果时返回“知识库中没有找到相关信息”
3. **生成层**：理想情况应该直接拒答；当前 Agent 实现里工具只返回一句自然语言，模型仍可能继续生成，这是已知限制

**阈值怎么定**：
- 正样本从测试集抽样；负样本分 easy（天气/菜谱/电影）和 hard（版本号、新特性、价格等近域但库内没有）
- 分别报告 `FPR = FP/(FP+TN)` 和 `FDR = FP/(TP+FP)`
- 旧文档把 `1 - precision` 写成“幻觉率 1%”，这个口径不准确，已修正

**面试话术**：
> “我在检索层加了降级策略：距离超过阈值就返回空，工具层返回‘知识库中没有找到’。但我会明确说，这还不是端到端拒答——Agent 收到工具结果后仍可能继续生成，所以真正的拒答要在 graph 层做分支，或者加一个‘资料是否充分’的判断。阈值本身也有局限：只看向量 top-1、在 BM25 融合之前判断，近域但库外的问题可能漏过去。所以我把 easy/hard 负样本分开评，不把阈值接受率叫成幻觉率。”
